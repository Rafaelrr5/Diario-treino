# Diário de Treino

Registro de cargas e repetições da ficha ABC (A peito/ombros/tríceps, B pernas/abdômen, C costas/bíceps).

- Abra pelo celular e use "Adicionar à tela inicial" para abrir como app (funciona sem internet).
- O próximo treino é sugerido pela rotação A → B → C, mesmo na semana seguinte.
- Cada exercício mostra a última carga, o recorde e a dica de progressão da ficha: bateu o topo da faixa em todas as séries, suba o menor incremento.
- Os dados ficam só no navegador do aparelho (localStorage). Use **Backup → Baixar backup** de vez em quando.

Testes da lógica: `node --test`.
